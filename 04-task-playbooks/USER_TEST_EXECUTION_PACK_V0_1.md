# PATH v1 原型测试执行包

> **状态：已推迟（deferred）。** 正式用户测试由 [ADR-002](../05-decisions/ADR-002-defer-formal-user-testing.md) 推迟至 v0.3 前执行；届时按可运行产品形态修订后复用。

## 目的

本测试验证一个闭环是否成立：用户能否理解自己为什么获得某个训练建议、在现实不匹配时能否安全修改，以及在复盘后是否仍保有下一步的决定权。

它不验证训练处方是否适合参与者，不提供医疗、康复、营养或动作质量意见，也不测试长期留存和付费。

## 招募目标

招募 8-12 名成年人，每人 35 分钟；优先覆盖下表三种状态，而非按体重、身材或训练成绩筛选。

| 组别 | 数量 | 招募条件 | 首要验证 |
|---|---:|---|---|
| 重返 | 3-4 | 过去 8 周没有规律训练，或最近正重新开始 | 中断后是否愿意再次进入 |
| 建立规律 | 3-4 | 近 2-6 个月每周训练约 1-2 次，尚无稳定计划 | Mission 与短版是否贴合现实 |
| 初步自主训练 | 3-4 | 近 3 个月每周训练 >= 2 次，曾记录训练或跟随计划 | 证据复盘与阶段调整是否可信 |

不招募目前有急性伤病、医生限制运动、急性饮食失调风险或不愿讨论任何运动限制的人。筛选只问是否存在需避免的动作/强度，不收集病历、药物或诊断。

## 可直接发布的招募文案

> 我们正在测试一款帮助人理解训练、安排下一步、并在中断后重新开始的健身工具原型。测试约 35 分钟，不需要实际运动，也不会评估你的身材或训练水平。界面中的数据均为虚构样例。我们想了解：它是否清楚、是否尊重你的现实限制、以及你是否愿意不同意它。你可以跳过任何问题或随时停止。

招募渠道可优先选择熟人转介绍、同城健身房常客、运动社群或公司运动群。不要承诺减脂、增肌、动作指导或专业健康建议；不以免费训练建议交换敏感身体信息。

## 筛选表单

只收集以下字段，并为每条设置“不愿透露”：

1. 年龄段：18-21 / 22-29 / 30-39 / 40+。
2. 最近 8 周平均每周主动训练次数：0 / 1 / 2 / 3+。
3. 最近一次连续停练 4 周以上是否发生过：是 / 否 / 不愿透露。
4. 当前主要训练场地：家中 / 商业健身房 / 团课或工作室 / 户外 / 其他。
5. 平常一次可用时长：少于 20 分钟 / 20-35 分钟 / 35-60 分钟 / 60 分钟以上。
6. 是否使用过训练计划、训练记录、饮食/体重或穿戴设备工具：多选。
7. 目前最想解决的一个训练问题：自由文本，限 100 字。
8. 是否存在目前需要避免的动作或强度：是 / 否 / 不确定；只收“是否”，不追问原因。
9. 是否同意匿名笔记：是 / 否。录音/录屏必须单独二次同意。

## 测试前检查

- 打开 [可体验原型](http://127.0.0.1:4173/prototype-v1.html)，确认三条路径、短版/恢复版、替换动作、风险分流和复盘均可用。
- 使用参与者编号，不显示或记录真实姓名、体重、照片、病历、账号或运动历史。
- 准备三张情境卡；让用户操作样例人物，不对用户本人做计划。
- 记录员和主持人可为同一人，但不得在参与者卡住时教他怎样点击。

## 35 分钟执行脚本

### 开场，0-3 分钟

照读：

> 今天测试的是产品原型，不是在测试你，也不会为你制定训练或健康方案。请边操作边说出你在看什么、哪里犹豫、哪里不同意。任何问题都可以跳过，随时可以停止。

单独询问：是否同意匿名笔记；若需要录音/录屏，再单独征得同意。

### 热身，3-6 分钟

只问三题：

1. 最近一次主动训练或原本打算训练是什么时候？
2. 有没有某次计划看起来合理、现实却做不了的经历？
3. 你目前怎样判断一段训练要维持、调整或暂停？

### 情境一：重返，6-14 分钟

给出情境：过去 8 周因工作忙中断；今天只有 20 分钟；精力一般；没有急性或持续加重不适；器械不确定。

任务：选择下一步，指出 Mission，选择或修改当天版本，训练结束后说明留下了什么记录、下次还缺什么。

只在参与者没有自然表达时追问：这 8 周是否被产品表达成失败？若出现持续加重疼痛，系统应如何做？

### 情境二：现实不匹配，14-22 分钟

给出情境：计划 55 分钟下肢训练，但午休只剩 25 分钟；轻微酸胀、无尖锐或加重疼痛；目标器械被占用。

任务：解释推荐理由；选完整/短版/恢复；替换或跳过动作；记录一组和主观难度；说出希望系统下次怎样回应。

### 情境三：体重未变时的复盘，22-30 分钟

给出情境：4 周内大部分训练完成；相近条件下腿举表现稳定/小幅变化；体重变化不明显；睡眠波动；只有一次围度记录。

任务：区分事实、观察和待确认；选择、修改或拒绝候选路线；评价阶段现场记录是否说过头、是否愿意分享。

### 收尾，30-35 分钟

不看屏幕依次问：

1. 你的 Mission 是什么？
2. 系统为什么给出刚才那节训练？说出两条依据。
3. 复盘中什么是事实、什么仍不能确认？
4. 你在哪里能不同意系统？你会在什么时候这样做？
5. 哪一刻最信任？哪一刻最不信任或最想退出？

## 汇总与判定

每场结束后立即把问题归入以下标签，避免凭印象讨论：

| 标签 | 定义 | 决策 |
|---|---|---|
| `BLOCKER` | 无法完成核心路径，或误解安全/决策权 | 下轮原型前必须修复 |
| `TRUST` | 不理解依据、怀疑黑箱、误认为系统强制 | 改理由、证据或控制入口 |
| `SHAME` | 短版/暂停/体重表达引发失败感或羞耻 | 改交互和文案，不用奖励覆盖 |
| `FRICTION` | 多步记录、术语、输入或操作阻碍 | 简化默认输入与现场流程 |
| `DELIGHT` | 路线、现场记录、回归表达增强理解而不误导 | 保留并测试是否可扩展 |

在 8-12 场后只召开一次 60 分钟判定会：先逐项回看原话与完成情况，再决定 `保留 / 修改 / 删除 / 延后`。不能用“大家觉得不错”替代具体任务表现。

## 隐私与安全红线

- 不记录真实健康诊断、身材照片、体重、饮食细节或登录信息。
- 参与者报告疼痛、伤病或饮食焦虑时，不追问和不提供建议；可提醒其跳过当前问题。
- 原型始终标为虚构样例。任何录音/录屏必须可撤回，并在汇总后删除原始文件。
- 研究笔记只使用编号；公开分享只使用汇总主题，不能包含可识别原话。

## 退出条件

出现以下任一情况时，暂停扩展功能并回到核心闭环：

- 多名参与者无法解释推荐的两条输入依据。
- 多名参与者把短版、恢复或暂停理解为失败或惩罚。
- 风险情境被理解为“产品确认我安全”或“产品会诊断我”。
- 复盘页面让用户把稳定表现、体重或外观直接读成身体改变保证。
